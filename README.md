# Концепты сайтов

Статичные HTML/CSS-концепты, у каждого есть сайт и мудборд.

| Проект | Что это | Сайт | Мудборд |
|---|---|---|---|
| ÉTOFFE | Лендинг мастерской сумок на заказ | `etoffe/` | `etoffe/moodboard.html` |
| Сальдо | Главная сайта бухгалтерских услуг | `saldo/` | `saldo/moodboard.html` |
| Фарфор | Прототип сайта стоматологии, 10 страниц | `farfor/` | `farfor/moodboard.html` |
| ОВАЛ | Мебельный магазин: главная и каталог с фильтрами | `oval/`, `oval/catalog.html` | `oval/moodboard.html` |
| ONDA | Промо-лендинг беспроводных наушников | `onda/` | `onda/moodboard.html` |

Общая страница — `index.html`. Тексты в квадратных скобках (`[ЦЕНА]`, `[ТЕЛЕФОН]`) — заглушки под данные клиента. Картинки сгенерированы для концептов, на реальных сайтах их заменяют фото.
